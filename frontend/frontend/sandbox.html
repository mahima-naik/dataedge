Vernika Sandbox

How it works

Backend flow

  • Each agent gets a persisted UUID sandbox-{id} campaign key for the live websocket leg.
  • _role=demo routes persona anchors while your custom prompt carries the behavioural spec.
  • VOBIZ_PUBLIC_BASE_URL must expose /vobiz/answer to Vobiz.
  • Optional per-agent caller ID / auth overrides fall back to VOBIZ_* globals.

Docs

API

REST: GET/POST /api/sandbox/agents, PATCH/DELETE /api/sandbox/agents/{id}, dial POST /api/sandbox/agents/{id}/dial body {"to":"+91…"}.
